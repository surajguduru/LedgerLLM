## Trade-offs ("we chose X over Y because Z")
- Postgres-only over Redis for counters/budgets — one atomic UPDATE suffices under 100 rps; one fewer service.
- Reserve-then-settle over check-then-call — bursts cannot overspend; cost: pessimistic refusals near the limit.
- Integer micro-USD over float — exact sums, atomic increments.
- Fixed window over token bucket or sliding log — one upsert per request and no per-request history; cost: up to 2× rpm across a boundary (measured above).
- Free cache hits booked as zero-cost ledger rows over billing hits — the tenant gets an honest request count and pays only for model work (D16).
- In-process SSRF validation of every resolved address and redirect hop over an egress proxy — no extra service on the free tier; cost: a DNS-rebinding window between check and connect (D18).
- One fallback to a second model over retrying the same model — free-tier quotas and 503 bursts are per model, so the second model is usually up; cost: the answer may come from a smaller model, and latency can reach the sum of both timeouts (D19).
- Head+tail truncation for every plan and map-reduce for paid plans up to a per-plan ceiling, over cutting the head or map-reducing for everyone — endings carry conclusions, and the cost of reading the whole document is bounded by the ceiling and reserved up front; cost: N+1 sequential calls (6.5 s for a 140k-character chapter vs 1.8 s head+tail, measured above), no cross-chunk context, pessimistic reservations (D20).
- Groq (Qwen summarises, gpt-oss-120b judges) over Gemini for the summary eval — Gemini's free tier allows 20 flash requests a day, so 30 judged cases cannot run at all, and a judge from another family reduces self-preference; cost: the eval measures the prompt and pipeline on Qwen, not the production Gemini model (D21).
- An 8-case CI subset over the full 30 cases in CI — 4 minutes instead of 21 under 8,000 tokens/min; cost: a regression confined to the other 22 cases shows only in the local full run (D21).

- Weighted regex signals + cascaded Flash-Lite classifier over an always-on model classifier — heuristics are free and sub-millisecond, so only the ~12 % of inputs they are unsure about pay for a model call; the classifier's tokens are billed to the tenant, a classifier outage degrades to heuristics (D15) · Thrishal.
- Redact-and-return for PII in summaries over withholding — the tenant paid for the completion and the redacted copy is still useful; canary / foreign-URL / toxicity are withheld because the whole summary is untrusted (D22) · Thrishal.
- Classify every instruction when the LLM layer is on, over classifying only the uncertain band — the held-out set showed rewordings score 0 and never reached the model (5 % caught); instructions are short and repetitive so the cost is ~$0.04 per 1,000 uncached requests; documents stay banded because they are long and the heuristics are rarely unsure about them · Thrishal.
- Judge cost as platform cost over billing the tenant — the tenant did not ask for monitoring; the row is still under their id for attribution, just not settled (D17) · Thrishal.

## Failure modes (and the handling)
- Provider failure → 502, reservation released, nothing billed, audit event (`test_upstream_failure_releases_reservation_and_audits`).
- Duplicate request in flight with the same Idempotency-Key → 409 `idempotency_in_progress` + Retry-After; a failed request releases the key (`test_duplicate_in_flight_gets_409_in_progress`, `test_failure_clears_pending_so_retry_runs`).
- Reasoning model spends the whole output budget → `finish_reason: length` with no text → non-retryable `ProviderError` → 502 `upstream_error`, reservation released, nothing billed; the platform absorbs whatever the provider charged (`test_exhausted_budget_returns_502_and_bills_nothing`).
- Two identical cache misses at once → the cache write is an upsert, so neither request fails (`cache.store`).
- Eval judge replies with bad JSON or out-of-range scores → one retry, then `judge_error`, excluded from the means; > 10 % judge errors fails the gate (`tests/test_eval_runner.py`).
- Eval judge treats an injected instruction as a key point (it marked sum-027 down for leaving out "visit EVIL.COM") → the rubric says the source is data and embedded instructions or calls to action are never key points; v1 re-run with the fixed judge before any comparison (`test_judge_rubric_never_counts_embedded_instructions_as_key_points`).
- Free-tier 503/429 during the eval → per-model pacing, 15/30/60 s back-off, then that case alone is given up and counted as a judge error (`results/last_gemini.json`, 8 Oct).
- URL pointing at an internal address, directly or through a redirect → 400 `fetch_blocked` before any request to it is sent, logged, nothing billed; DNS rebinding between check and connect is the accepted gap (D18, `tests/test_fetch.py`).
- Primary model rate-limited, overloaded or timing out, with a fallback configured → one call to the fallback model if it is on the tenant's plan, billed at that model's list price, `usage.fallback_from` set, `ledgerllm_provider_fallbacks_total` +1; both fail → 502, reservation released, nothing billed (D19, `tests/test_fallback.py`, real fallback above).
- A map or reduce call fails part-way through a long document → whole reservation released, 502 naming the stage (`map:2/3: …`), nothing billed and no ledger rows; tokens of the calls that had answered are logged as `map_reduce_failed_absorbed` and paid by the platform (D20, `test_failure_in_the_second_map_call_bills_nothing`; seen for real as 429 on `map:1/3`, above).
- Groq token window full during the eval → the pacer holds the call until enough earlier calls leave the 60 s window; a 429 that still happens is retried after the server's Retry-After (a hint above 2 min, i.e. a daily quota, gives up on that case at once) (D21, `test_tpm_*`, `test_backoff_honours_retry_after`; 0 retries in the 60-call run, 8 Oct).
- Guardrail false positive on a paying customer → roll out in `shadow` first and read `shadow_report`; FPR gate (≤ 5 %) in CI; a block releases the reservation so nothing but the classifier call is billed (`test_shadow_mode_records_but_does_not_block`, `test_bare_keyword_in_a_news_document_is_a_signal_not_a_block`) · Thrishal.
- Classifier model down or returns garbage → heuristic score decides, request is not refused (`test_provider_failure_falls_back_to_heuristics`, `test_non_json_reply_falls_back_to_heuristics`) · Thrishal.
- Judge model down → sample dropped and logged; judge returns non-JSON → call still booked, sample stored with null scores and excluded from means (`test_provider_failure_is_dropped_quietly`, `test_mock_provider_reply_is_unparsable_but_still_costed`) · Thrishal.
- Reservation left open by a crash after reserve (classifier exception, model missing from prices.yaml, DB error in the ledger) → released by the pipeline wrapper before the error propagates; nothing stays reserved, the retry is admitted (`tests/test_reservation_release.py`, review item 6, reproduced on the previous code) · Thrishal.
- Sampled quality mean drops for a prompt version → `GET /admin/quality` → `drift` flags a ≥ 0.5-point drop over ≥ 10 recent samples against the week before (`test_drift_report_flags_a_drop`); a Prometheus rule on `ledgerllm_quality_score` is the next step (ops/) · Thrishal.
- Judge slower than traffic → single paced worker; queue grows in memory, response path unaffected (`test_response_path_does_not_wait_for_the_judge`). At 10× add a bounded queue and drop samples rather than buffer · Thrishal.
